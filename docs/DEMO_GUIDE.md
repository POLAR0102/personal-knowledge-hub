# 答辩演示流程

## 1. 演示前检查

至少提前一天完成一次全流程彩排：

```powershell
cd C:\Users\polar\Documents\knowledge\backend
.\.venv\Scripts\python.exe -m pytest -q

cd ..\frontend
npm run lint
npm run build
```

演示前确认：

- 前后端健康检查正常。
- 演示账号能够登录。
- Chat API 余额和网络正常，Key 没有出现在页面、日志和截图中。
- 本地 Embedding 模型已经下载，避免现场等待。
- 演示文档已经准备，但保留一个未处理文档用于展示完整流程。
- 已创建演示前备份。

## 2. 推荐演示资料

演示脚本可生成一份包含以下事实的 Markdown 文档：

- 项目代号：PKH-2026
- 技术：React、FastAPI、ChromaDB、RAG
- 核心版本计划：14 天
- 项目负责人：张三

本地创建：

```powershell
cd backend
.\.venv\Scripts\python.exe -m scripts.seed_demo
```

## 3. 8 至 10 分钟主流程

1. **系统入口（约 30 秒）**
   - 打开 Dashboard。
   - 说明前端 React、后端 FastAPI、SQLite 业务数据和 ChromaDB 向量数据。
   - 展示 Dashboard 的真实知识库、文档、会话和笔记数量。

2. **用户隔离（约 30 秒）**
   - 简要展示登录。
   - 说明 JWT、ProtectedRoute，以及后端所有资源查询都附带当前用户条件。

3. **文档处理（约 2 分钟）**
   - 进入演示知识库。
   - 上传或使用待处理的 Markdown 文档。
   - 点击“开始处理”，展示 `pending → processing → completed`。
   - 打开文本片段，指出标题、页码/段落来源和 Chunk 顺序。
   - 再次处理，说明旧 Chunk 会被替换而不是翻倍。

4. **向量索引与语义检索（约 1 分钟）**
   - 点击“建立索引”，展示 `not_indexed → indexing → indexed`。
   - 在语义检索页提问“核心版本需要多久完成？”。
   - 指出返回的是原文片段和 cosine distance，并不是伪造的相似度百分比。

5. **RAG 问答与真实引用（约 2 分钟）**
   - 新建会话并选择演示知识库。
   - 提问“项目代号是什么？”或“系统使用了哪些技术？”。
   - 展示 AI 回答、文件名、Chunk、页码/标题和真实引用片段。
   - 刷新页面，展示会话和引用快照仍然存在。

6. **固定工作流 Agent（约 2 分钟）**
   - 选择 `study_plan` 或 `topic_note`。
   - 输入“根据知识库中的 FastAPI 内容生成七天学习计划”。
   - 说明流程固定为“验证 → 检索 → 整理 → 生成 Markdown → 引用”，模型不能访问网络、Shell 或任意工具。
   - 完成后点击“保存为笔记”。

7. **知识管理完整度（约 1 分钟）**
   - 在笔记页展示 Markdown 渲染和 Agent 来源。
   - 给文档添加标签、收藏，再到收藏页和文档页组合筛选。
   - 回到 Dashboard 展示真实数量变化。

## 5. 现场故障预案

- **Chat API 临时不可用**：展示语义检索结果，说明检索层与生成层解耦；不要把检索片段说成 AI 回答。
- **首次索引很慢**：提前下载本地 Embedding 模型，并保留一个已索引知识库作为备用。
- **网络断开**：本地 Embedding、文档管理、检索和历史数据仍可演示；外部 Chat 生成需要网络。
- **新上传文件失败**：切换到预先准备的待处理演示文档，同时保留错误信息用于说明系统状态管理。
- **演示数据被误删**：停止服务，按备份文档恢复，不要现场执行 `docker compose down -v`。

## 6. 答辩时可强调的设计点

- SQLite 与 ChromaDB 不能构成同一数据库事务，因此重新索引采用“先删旧向量、失败标记、再次完整重试”的补偿策略。
- RAG 引用来自实际检索结果，历史消息保存引用快照，文档更新后仍能展示当时依据。
- 文档解析、清洗、切分、Embedding、向量存储和 Chat Model 都分层，便于独立测试和替换。
- Agent 是安全、可说明的固定工作流，不展示模型内部思维过程，也不开放高风险工具。
